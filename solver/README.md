# 居灵 TakeHome 工程题 - 二维装箱求解器

## 一、AI 工具使用说明

1. 使用的 AI 工具：Alife 桌面助手（内置大语言模型:DeepSeek v4.1flash）。
2. AI 主要帮助的部分：
   - 思路拆解：将题目拆解为几何建模、贴墙策略、碰撞检测、约束处理四个子问题。
   - 代码生成：生成 Vec2 / Polygon / RectItem / Solver / Json / Main 等 Java 类骨架。
   - Debug：协助定位编译期类型错误、运行期文件路径问题。
3. 自己理解并调整的关键逻辑：
   - 贴墙候选位置生成：沿轮廓边滑动 + 内侧法线偏移，保证物体优先贴墙。
   - 冰箱开门边净空判断：开门边外侧预留净空区，且该区不越界、不与其他物体重叠。
   - 内开门禁放区：以门线段为一边向房间内部延伸出 N x N 正方形。

## 二、核心代码实现逻辑

### 1. 几何建模
- `Vec2`：二维向量/点，提供加减、点乘、叉乘、旋转等运算。
- `Polygon`：简单多边形（顶点顺序首尾相连），提供点在多边形内判定 `contains`、边相交判定等。
- `RectItem`：可旋转矩形物体，保存名称、类型、长宽、中心坐标、旋转角度、开门边索引；提供四角点计算与分离轴定理（SAT）重叠判定。

### 2. 门的处理
- 外开门：门线段作为边界，不额外生成禁放区。
- 内开门：以门线段为一边，向多边形内部延伸 N x N（N 为门宽），构成正方形禁放区。

### 3. 放置算法（贪心 + 贴墙优先）
1. 物体按面积从大到小排序，冰箱、大货架优先放置。
2. 对每个物体，遍历两个朝向（0° / 90°），并对每一条轮廓边做候选位置生成：
   - 将物体"背面"贴在该轮廓边上，中心位于内侧法线方向 w/2 处；
   - 沿边滑动多个采样位置，逐一尝试。
3. 每个候选位置执行碰撞检测：
   - 四角点均在多边形内；
   - 边不与多边形边相交；
   - 不与门禁放区重叠；
   - 不与已放物体重叠；
   - 冰箱开门边外侧留有净空，且该净空不越界、不被其他物体占用。

### 4. 冰箱开门边
- 冰箱的两条长边之一为开门边，自动选择外法线更朝向房间内部的那条；
- 开门边外侧预留净空（深度取冰箱短边宽度），净空区内不得有其他物体。

### 5. 输出
- 全部物体放置成功则输出"可行"，并打印每件物体的中心坐标与旋转角度；
- 任一件放不下则输出"不可行：无法摆放 XXX"。

## 三、运行环境及运行方式

### 运行环境
- JDK 17 及以上
- IDEA 或命令行均可，无需第三方依赖，JSON 解析为自实现。

### IDEA 运行
1. 用 IDEA 打开 `solver` 目录；
2. 确认 Project SDK 与 Language Level 均为 17；
3. 运行 `takehome.Main`，在 Program arguments 中填入示例文件名，如 `example1.json`；
4. 工作目录设为项目根目录 `solver`（示例 json 已放在该目录）。

### 命令行运行
```
javac -encoding UTF-8 -d out src/takehome/*.java
java -cp out takehome.Main example1.json
```

## 五、已知限制与待确认点

- 题目要求"优先贴墙"与"冰箱开门边不能放任何东西"在空间紧张时可能互相冲突。
- 当前实现按"开门边前方需要一整块门宽的开合净空"处理（较严格）。
- 若题目本意仅为"开门边线段本身不贴物体"，可将净空深度调小，示例将更易全部可行。
